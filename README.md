# TCDNet

This repository provides the implementation of **TCDNet: Transmittance-Guided Thin Cloud Detection Network with Boundary-Aware Optimization**.

TCDNet is designed for thin cloud detection in optical remote sensing images. It introduces transmittance-guided feature augmentation, boundary-aware optimization, and uncertainty-informed decoding to improve the detection of semi-transparent thin clouds with weak contrast and blurred boundaries.

## Code

The original demo version of the TCDNet code has been preliminarily released in this repository.

We are currently organizing and cleaning the complete experimental code, including training, testing, and evaluation scripts. The full version will be continuously updated once the preparation is completed.

## Dataset

The datasets used in this study include SPARCS, the custom thin cloud dataset, L8-Biome, and additional real ZY303 and GF7 scenes.

### SPARCS Dataset

The SPARCS dataset is publicly available at:

- Link: https://emapr.ceoas.oregonstate.edu/sparcs/

### Custom Thin Cloud Dataset

The custom thin cloud dataset constructed in this study has been released via Baidu Netdisk:

- Link: https://pan.baidu.com/s/1MVP4IezvaDNasLn9dWaM2Q?pwd=9zpg  
- Extraction code: `9zpg`

### L8-Biome Dataset

The L8-Biome dataset is publicly available at:

- Link: https://landsat.usgs.gov/landsat-8-cloud-cover-assessment-validation-data

### Real World ZY303 and GF7 Scenes

Additional real satellite scenes used for generalization evaluation are available via Baidu Netdisk:
